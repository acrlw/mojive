# Viewer、资源和可替换仿真后端

## 产品边界

Electron 和浏览器共享交互式 viewer。无物理引擎时，URDF 浏览、场景树、姿态调整、
相机、材质、可见性、姿态时间轴及文档保存继续可用。加载物理模型之后，增加真实仿真、
驱动器输入、扰动、Environment 设置和仿真状态回放。暂不增加拓扑建模、关节结构编辑
或庞大的逐物体物理属性编辑器。

Environment 是场景的环境实体；渲染环境由 viewer 管理，物理环境由当前后端提供。
基础参数直接可见，算法及高级求解参数按组折叠，初始化继承模型自身的值。
“重置仿真状态”和“恢复模型的环境参数”是两个独立操作。

## 所有权和数据流

| 模块 | 责任 | 不允许的依赖 |
| --- | --- | --- |
| `resources/` | 模型资源包、相对路径、资源目录、预览输入 | React、物理运行时 |
| `physics/contracts.ts` | 后端能力、稳定场景描述、动态帧、命令、状态快照 | Three.js、React、MuJoCo |
| `physics/SimulationSession.ts` | 加载和释放、播放调度、命令排序、错误状态、订阅 | React、具体引擎 |
| `physics/backends/mujoco/` | WASM 生命周期、编译、数据映射、选项校验、状态读写 | UI、Three.js |
| `physics/SceneBinding.ts` | 中性场景描述到现有 viewer 文档，按显式 ID 应用动态帧 | MuJoCo |
| `physics/PhysicsDocument.ts` | 组合文档、场景绑定和仿真会话，安装命令路由 | React、具体引擎 |
| `assets/` | 资源浏览、检索、收藏、独立预览的会话 | 当前文档的可变状态 |
| UI presenters | 使用共享控件，调用 session 命令，按能力展示操作 | WASM 指针、引擎枚举、引擎对象 |

WASM 运行在专用 Worker。默认使用单线程官方发行包，不要求 Electron 专用能力或
SharedArrayBuffer。主线程仅交换中性描述、帧和命令，不传递引擎句柄。后续后端实现
相同协议；已有姿态编辑不伪装为物理引擎。

加载先在候选后端中完成编译、场景构建和首帧验证，成功后才替换当前文档。失败保留
原文档，错误进入输出面板。替换、取消和关闭均释放 Worker、模型、数据与预览资源。
场景结构有明确的 source ID；快照只有 source ID、后端和状态格式匹配才能恢复。

稳定结构只发送一次。动态帧使用紧凑的 typed arrays；渲染器按固定索引更新位置和旋转，
不逐帧重建树或 mesh。物理状态和几何姿态分开：恢复仿真需要速度、内部状态、控制量
及环境参数，不能只回写渲染 transform。

## 命令和历史

所有物理写入由 session 在步进边界串行执行。参数批量校验后原子应用；失败不得部分
写入。一个拖拽只有一条 undo transaction。Environment 的默认值在模型加载时保存，
恢复默认不能把不同模型的设置混用。后端能力决定可写字段，不给只读远程源显示假开关。

关节姿态使用后端提供的显式 joint ID；驱动器输入使用 actuator ID，二者不能混为一谈。
无后端的 URDF transmission 仍展示元数据，不捏造可运行的驱动器。

扰动手势只持有 pointer/button 的操作所有权和世界空间目标，通过文档的中性命令端口
发送目标。后端负责产生力，松开或取消时清理。物理快照包含持有中的扰动状态，保证
录制恢复后仍能继续；普通场景不安装该能力，也不因此失去原有的 gizmo 交互。

## 时间轴和资产

保留关键帧、片段、快照三个轨道。姿态片段与物理片段显式区分数据格式，物理片段包含
恢复所需的完整状态与配置。录制无预设终点；播放循环范围和可见范围不能限制录制长度。

项目文件管理器负责文件；Asset Browser 负责发现模型和预览。预览使用独立文档及相机，
不替换正在工作的场景。打开模型是显式动作；收藏、最近使用和缩略图不保存引擎句柄。

目前目录使用格式图标，预览提供实际 3D 场景；自动缩略图缓存尚未实现。MuJoCo
适配器映射刚体图元、mesh、heightfield、动态 flex/skin 表面、关节、驱动器、相机及灯光，
并使用编译后的 RGB/RGBA 表面纹理、天空盒和雾设置。材质应用基础颜色、透明度、
emission、roughness 和 metallic；其他纹理角色，以及原生 specular、shininess、
reflectance 的渲染行为尚未复现。Three.js 的画面不宣称与 MuJoCo 原生渲染等同。

模型语料检查覆盖编译、场景构建、步进和状态恢复，不等同于逐模型的画面对比或时间轴
验收。当前检查跳过带 plugin 的条目；部分不依赖 plugin 的输入仍会在引擎 schema 或
mesh 校验阶段失败。实际桌面录制、回放和文档往返另由物理交互验收覆盖。
