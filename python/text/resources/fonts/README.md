# MiSans UI fonts

Mojive uses MiSans Regular and Semibold for its portable Latin and Simplified Chinese UI.
These are unmodified files from Xiaomi’s official MiSans distribution, retrieved 2026-10-17.

- Official download: https://hyperos.mi.com/font/zh/download/
- Archive: https://hyperos.mi.com/font-download/MiSans.zip
- License: [MiSans Fonts License Agreement](MiSans-License.pdf)
- Embedding guidance: https://hyperos.mi.com/font/en/faq/
